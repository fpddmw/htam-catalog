## 当前问题对应的设计

| 问题 | 已落实的约定 | 仍需用实现确认 |
| --- | --- | --- |
| 交付形态 | 本项目源码、命令入口、测试与样例，可按项目复用 | 目标宿主安装与调用检查 |
| 模块基本单位 | 已确认按具体技术与适用条件组织；区分类别、模块、实例 | 多来源记录的同一性及关联判断 |
| 工艺原子 | 当前资料及观察粒度下可独立复用；模块内部可以继续包含子模块 | 整体与分解表达的边界和证据对应 |
| 探索目录 | 本地保存功能、同义词、输入输出及条件摘要，派生索引服务跨工艺查找 | 真实查询召回的候选、匹配理由和未知项 |
| 外部映射 | 模块与 LCA 记录可多对多关联，文献模块可先于完整清单入库 | 映射范围、来源刷新及本地补充保留 |
| 递归工艺 | 子实例引用固定过程版本，父级保存边界映射 | 多层展开、包含环诊断、保存恢复 |
| 定义与实例 | 公共模板复用，方案内独立参数覆盖 | 同一模板重复使用时互不串改 |
| 多粒度表示 | 已确认同一模块下整体和不同拆分表达可并存 | 汇总与子过程计量边界、来源差异表达 |
| 工艺拆分 | 有来源的子过程、连接、数量归属和未知项 | 信息不足时部分拆分的保存与检查 |
| 参数修改 | 公式、范围和来源是模型数据 | 单位、依赖、未知值传播及适用范围 |
| 重组条件 | 规则表达已知接口和约束，未知项可保留 | 物性和工况匹配、适配工序的表达 |
| 新工艺 | 保留假设、缺口和证据地位，模型关系逐步补充 | 所需实验、文献或过程模拟模型 |
| 回流与共享设施 | 分开包含关系、物料循环和数学求解；显式物理实例 | 循环求解接入及共享计量 |
| 数据与版本 | 本地卡片及索引服务探索，详细 LCA 数据按需引用，模型存储优先复用；可变草稿记录实际内容 | 上游版本回退、修改恢复、来源刷新和索引重建 |
| AI 与程序 | AI 辅助语义和研究判断，程序执行明确操作 | 输入输出契约及未覆盖情况 |
| 天工复用 | 两套 CLI/Skills 分开记录版本和职责 | 逐操作兼容性与目标格式损失 |
| 组内接入 | 项目代码、工具依赖、数据三者分开，路径显式指定 | 可搬迁性、许可与共同维护方式 |
