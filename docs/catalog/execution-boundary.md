# AI 判断与固定执行的边界

本页记录程序职责。当前 [catalog.py](../../src/htam_catalog/catalog.py) 已实现卡片读写与修订、字段检索、来源刷新、索引重建、层级读取和声明条件检查；参数求值、实例编辑和完整计算适配仍为后续设计，详见[本地命令](catalog-cli.md)。

| 工作 | AI 或研究人员 | 已明确后交给程序 |
| --- | --- | --- |
| 阅读来源 | 理解工艺、口径、证据地位及矛盾 | 保存原件、建立引用、转换已知格式 |
| 工艺目录 | 确认模块身份、功能、同义词和来源对应，整理接口条件 | 保存/读回卡片、建立字段索引、处理刷新差异、重建索引 |
| 过程拆分 | 确定子工序、数量归属和证据 | 建立实例、连接、边界映射和新版本 |
| 递归组合 | 选择模块和粒度 | 解析固定引用、检查包含环、展开及恢复 |
| 改参数 | 选择参数、公式和适用范围 | 换算、依赖更新、公式求值、批量扫描 |
| 路径重组 | 提出潜在组合、新工艺和适配假设 | 按接口定向查找，检查已知条件，返回理由及未知项，连接、替换和筛选 |
| LCA 适配 | 确定边界、映射歧义和比较条件 | 固定格式转换、调用求解器、保存结果 |
| 数据维护 | 决定模型修订和冲突取舍 | 事务、版本、查询、备份和恢复 |

核心代码位于 `src/htam_catalog/`，命令入口位于 `scripts/`。AI 可以在开发时协助编写代码；运行时程序按已确定逻辑完成任务，不需要 AI 每步参与。

例如含水率关系和边界已经明确，程序可连续读取固定模型、生成参数组、计算派生量、检查接收阈值、保存和导出。缺公式或未知条件返回具体诊断；由 AI 或研究人员补充依据后，以新模型版本继续。

AI 提出候选物理模型，程序运行该模型。结构正确、质量平衡、工况满足与工程可行性分别报告；结论范围对应已建模的条件及其证据。

首批固定操作聚焦卡片保存/读取、功能与接口检索、来源映射、层级引用和索引重建；随后依据上游验证补充实例修改、已声明关系求值和天工适配。程序返回候选理由、已检查条件、未知项、状态及产物位置。既定字段过滤和规则检查可直接由程序执行，语义判断按需要调用 AI。

固定公式限于已实现的表达能力；联立方程、复杂物性和循环求解按需要接入成熟工具。对模型数据中的公式采用明确的表达与执行约定，不把来源文字直接作为任意程序执行。
