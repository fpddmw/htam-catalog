# 递归过程模型约定

更新：2026-09-27。状态：模型设计约定0.5。卡片格式v1及本地目录操作已实现，见[本地命令](catalog-cli.md)；本页仍包含尚未实现的实例参数编辑、数量传播和定量模型操作。卡片和探索索引的语义见[目录约定](module-catalog.md)。官方 CLI 的基础汇总已验证，实际组内部署及认证接口仍待确认。

## 数据归属与复用

组内 LCA 数据是现有过程、流、单位、清单及其来源的优先数据源。按现有标识和可获得的版本引用，通过已有接口读取所需内容，沿用其数据结构与计算能力。下面列出的模型内容是需要访问或关联的信息，不要求在本地各建一份主数据。

本地保存面向探索的模块卡片、接口摘要、引导字段与派生索引；上游已有字段也可按来源提取到目录。方案中的实例、连接和保存操作优先使用现成能力，未覆盖的递归拆分、参数修改和适配关系另行扩展。文献或专利模块可以先记录部分知识，资料足够时形成现有系统可接受的过程草稿。

读取数据时只按任务需要取用；缓存或复现快照限定于选用的记录和必要依赖，保留其身份与来源。引用是否可重现取决于上游版本访问能力，接口不提供历史版本时记录实际获取内容及时间。全量同步 LCA 库不在当前设计范围。

## 已确认的对象边界

可复用模块以具体技术及其适用条件为基本单位。区分类别（如干燥）、模块（某技术和条件下的干燥过程）及实例（某方案中的一次使用）。类别用于组织检索，模块保存知识和来源，实例记录本次规模与参数设置。

同一模块可并存整体资料与不同拆分表达，各自保留来源、适用条件和差异；使用时明确选取。资料中采用相同过程名称，不自动确定它们是同一模块；具体的合并和关联规则仍需样例讨论。

“原子”是当前粒度下可独立复用的模块，不要求达到物理上最小工序。工艺卡片描述模块，接口是其对外摘要；模块与外部数据记录可以多对多关联，每条映射记录边界和支持范围。

## 记录对象

| 对象 | 保存内容 |
| --- | --- |
| 过程类别 | 用于检索的功能或技术分类，可关联多个具体模块 |
| 来源资产 | 文献/专利/数据库身份、版本、页表或字段位置、访问与许可、原件引用 |
| 过程定义及版本 | 稳定身份、实际返回版本与内容状态、输入输出接口、参数、适用条件和内部表示；可变草稿另记时间及内容散列 |
| 过程实例 | 在某方案中的独立身份、引用的定义版本、数量基础与参数覆盖 |
| 方案及版本 | 实例、连接、选择的表示、共同需求、边界与修改记录 |
| 运行记录 | 输入版本、参数、依赖工具版本、检查范围、状态、诊断和产物 |

模型的具体工艺组成、公式和适用条件以数据保存。程序实现读取、引用、检查、求值与保存这些模型的通用规则。新增可由当前表达方式承载的工艺时增加数据记录。

## 接口和数量

接口区分物料、能量、服务与环境交换，记录方向、身份、单位、数量基础、必要的组成/浓度/温压等性质及适用条件。采用外部流身份时保存其提供方、ID 和版本；名称相同只是匹配线索。

区分可调参数、来源观察、派生量和未知项。公式保留来源、依赖、单位、适用范围与选用理由。跨来源组合和推算有明确标记。数量未知时保留缺口，零值记录依据。混合、分流、多产出和联产品处理保留各自的数量与评价语义。

## 递归和复用

父过程保存子实例及固定定义版本引用，不递归复制全部文档。父级输入输出显式映射到子过程接口；映射表示边界对应，汇总时不额外复制一次物料交换。

例如“调质@1”引用“压滤@1”和“干燥@3”，并连接滤饼输出与干燥进料。更大生产线可以再引用“调质@1”。“干燥@4”发布后，旧调质版本继续引用“干燥@3”；明确升级会生成新版本。

包含关系能够有限展开；物料连接允许回流；公式依赖和联立方程分别处理。共享设施以同一物理实例及服务关系表达，按明确计量边界分配；引用同一模板建立的两台设备则是两个实例。

过程可保留整体清单、公式关系或子过程网络等表示。资料不完整时保留整体模块和未知项。一个运行固定选用的表示；父级汇总清单与其对应子过程清单共同计量时应说明互不重叠的覆盖范围。界面折叠展开保持已选模型不变。

## 修改与状态

修改请求应明确目标对象、预期旧版本、实例范围和变更内容。结构性拆分包括：子过程、连接、边界映射、数量归属、来源及残余未知项。程序检查结构，工艺判断提供拆分依据。

本项目目标是保存可恢复的方案状态；上游天工草稿可以在同一版本号下修改，版本号本身不保证内容固定。读取时核对请求与返回版本，必要时保存所选记录的内容散列和快照。自动产生的索引从记录的具体内容重建。运行分别记录结构是否通过、数量是否已解析、条件是否满足、是否成功导出或计算；任一维度未知时保持具体原因。

## 拟议持久化

本地工艺目录已采用版本化 JSON 卡片及可重建 JSON 索引，覆盖功能、接口、条件、来源和层级入口。SQLite 等后端按规模和使用结果选择。完整 LCA 库同步不作为前置。

既有详细 LCA 数据的权威记录留在原系统，按候选需要读取和缓存。方案连接、实例设置和版本优先通过经过核验的现有模型接口承载，缺口保存在工作区方案中。本地模块身份、原创判断及来源记录长期保留；来源刷新与派生索引更新遵循目录约定。

## 用样例落实的四项使用规则

以下规则用于卡片与方案样例。流、单位、参考量、参数及来源沿用可复用的定义，探索摘要保留与原字段的对应；重组所需的新关系或判断明确标注依据和作用范围。

| 问题 | 建议 | 需要走读的情况 |
| --- | --- | --- |
| 物料身份与性质 | 接口同时记录流身份、必要状态/组成及对其的要求；复用天工标识，行业性质逐步扩充 | 两股都叫“蒸汽”但压力不同；流标识已知而状态未知 |
| 数量基础与参数调整 | 保留原始数量基础和单位；区分原始观察、实例设置和派生量，记录调整依据与适用范围 | 每吨湿料与每吨干物质；改含水率后缺少耗热关系 |
| 连接与判断 | 允许记录候选连接，逐项表达已知条件满足、不满足或未知；适配工序显式记录 | 目标要求含水率低于15%，来料为20%或尚未知；增加干燥步骤 |
| 多来源与数值差异 | 单一来源可作为整份记录的默认依据；跨来源组合、推算和修改另行标注，差异保留备选与选用理由 | 相同技术的不同条件、数值冲突、整体与拆分表示之间的差异 |

物料适配和连接规则只给出其已覆盖条件下的检查结果。模块身份是否相同，应综合技术、边界和条件判断；参数差异可以是同一模块下的不同设置，技术变化可能需要关联的新模块，具体以实例走读确定。

先以整体模块、资料不完整的模块及复合模块落实卡片、接口检索和层级引用，保留跨工艺覆盖。随后使用可访问的原生过程/模型验证改参、保存重开和内层变化传播，确定适配缺口。整体资料可直接引用；核查聚焦变化与关键疑点。

## 导出

选定方案与表示，解析引用和数量后转换为目标格式。保留实例到导出项的对应，原始来源、未支持字段及映射状态。TIDAS 标识和单位沿用其受支持约定；本地递归结构保留在源模型及映射清单中。部分导出和完整可计算产物分别报告。
